## Audited boundaries

- Pure document, HLC, encode/diff/import/adopt/materialize: `packages/shared/src/meshLayout/`.
- Client logical grouping, tags and machine union, offline layout writes and replica strip/status: `packages/client-runtime/src/state/{meshLayout*,machineDisplay,meshMachines,projectGrouping}`.
- Persistence/gossip/validation: `apps/server/src/mesh/`; sessions, paths, runner, placement and launch: `apps/server/src/replicas/`.
- File access/relay and permission boundaries: `apps/server/src/files/`, `apps/server/src/peer/`, project MCP handlers.
- CLI review copy: `docs/skill-t3-next/scripts/`; the installed owner's skill is unchanged.
- Web/mobile workspace Machines and Mesh settings; web existing file picker gains an optional initial folder.

The source search found no hostname-dependent role decision in these product modules. Fixture names,
Russian CLI aliases and the isolated-bed machine names are not primary/authority assignments.
This ledger explicitly records where source review and existing tests are weaker than the requested
exhaustive conformance proof; those rows are not marked done.
